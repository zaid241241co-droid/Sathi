# SATHI Prototype

SATHI — "The route nobody warned her about."

This is a competition-ready interactive prototype for the Round 2 MVP demo.

## Core MVP features
1. Smart Route Risk Analysis
2. Time-Based Risk
3. Safe Haven Finder
4. Safer Alternative Route
5. Walk With Me

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build for deployment

```bash
npm run build
```

The prototype intentionally uses simulated route/map/risk data. This keeps the MVP focused on demonstrating the product experience rather than requiring a production backend.
